# DNFM Server

## 功能说明

1. **技能坐标配置**
   - 将技能坐标配置为所有键位的像素坐标。
   - 使用手机截屏功能 在训练场截图，用电脑上的画图工具获取图片中的技能坐标 鼠标放到技能上面左下角就是坐标，并将其配置在`hero/skill_skill_name` 文件夹下的 `common_skill.json` 文件中。

2. **技能映射**
   - 在 `hero/skill_skill_name` 文件夹下的 `common_skill.json` 文件中，将技能与 `hero/hero_skill` 文件夹内的技能名称对应。
   - `hero/skill_skill_name` 每个json 文件对应一个英雄
   - `hero_controller.py` 下面的 `self.skill_name_path`里面调整刷图英雄的顺序, `注意:` 游戏里面的角色也要按照这个顺序来
3. **共享变量 shared_variables.py**
   - `hero_num` 如果想从第一个角色开始刷 就切到这个英雄到赛利亚房间,变量修改 1 , 如果刷到第3个角色断开了 就把变量修改 3 角色切到第3个 到赛利亚房间重新启动. 
   - `mm_id` 关注微信公众号  `喵提醒` ,获取这个喵喵码替换 可以开启微信刷图进度提示
   - `role_dic` 角色的名字 按照出场顺序改写
   - `role_seq_coord` 游戏内点击左上角`选角` 前4个角色头像的坐标
4. **FPS 调整**
   - 在 `main.py` 文件的第26行找到 `fpsmax` 参数，调整其值到 5 到 30 之间。
   - 较低的 FPS 值会提高安全性，较高的 FPS 值会提高稳定性。

4. **英雄位置检测**
   - 如果英雄位置检测不准确，可以使用黑钻位置计算英雄位置。

5. **修改代码**
   - 仅需要修改 `game_action.py`  其他尽量不要改

## 项目启动步骤

1. 确保正确配置技能对应的坐标和技能映射。
2. 调整 FPS 设置以适应你的需求。
3.在赛利亚房间启动`main.py`
